**Goal:** Mirror Greg's new attribution data (lead UTM first/last-touch columns, `attribution_taxonomy`, `lead_engagements`, and the three `meta_*` ads tables) from the WGR database into CI, and surface canonical-channel attribution on the Leads and Sales pages (client deliverable 9, week of July 27).

**Architecture:** Extend the existing read-only WGR→CI sync (`backend/app/services/wgr_sync/`) with new mapped tables and lead columns, following the established native-PK and watermark patterns. Canonical channel is **never stored** — it is resolved at read time by a new `services/attribution.py` resolver that implements Greg's taxonomy contract (most-specific match wins, unmapped surfaces loudly). The Leads/Sales APIs expose `channel` computed from mirrored UTMs; the frontend renders it in place of the provenance `source`.

**Tech Stack:** FastAPI + SQLAlchemy (async) + Alembic, psycopg read-only WGR client, pytest; Next.js frontend.

## Global Constraints

- WGR DB is **strictly read-only** (session-level; `WGR_DATABASE_URL`). CI never writes upstream. All new tables are mirrors in CI's own DB (`DATABASE_URL`).
- `leads.source` is **provenance** (`'wgr'`), used by sync dedup — never overwrite it with marketing attribution. Marketing channel is a separate, computed value.
- Raw UTMs are mirrored verbatim and never rewritten (Greg's governance rule). Normalization happens only at read time through the taxonomy.
- Taxonomy matching contract (from Greg's migration `20260724_000000_attribution_taxonomy.sql`): case-insensitive on (observed_source, observed_medium, observed_content); NULL observed_* = wildcard; most-specific match wins (content beats source+medium beats source-only); ties broken by lowest id; no match → `unmapped:<source>/<medium>`; `include_in_channel_reporting=false` rows resolve but are excluded from channel-performance rollups.
- Alembic migrations are hand-written, not autogenerated (autogenerate emits spurious index drops — see `o6f7a8b9c0d1`'s docstring).
- Branch: `feature/wgr-attribution-sync` off latest `main`; merge to `staging`, never directly to `main`.
- No native browser dialogs in frontend; use shared atomic components (`frontend/src/components/ui/`).
- Any integration-surface change updates `INTEGRATIONS.md` in the same commit (project rule).
- Run backend tests as `cd backend && python -m pytest tests/<file> -v`. Frontend must pass `cd frontend && npm run build` before merge (Vercel fails silently on lint).
- After each task that modifies code files, rebuild the knowledge graph before committing (project rule): `python3 -c "from graphify.watch import _rebuild_code; from pathlib import Path; _rebuild_code(Path('.'))"` from the project root.

```python
"""Read-time canonical-channel resolution via attribution_taxonomy.

Implements Greg's taxonomy contract (WGR migration 20260724_000000): raw UTMs
are never rewritten; matching is case-insensitive; NULL observed_* is a
wildcard; the MOST SPECIFIC matching row wins (content beats source+medium
beats source-only), ties broken by lowest id; no match surfaces loudly as
``unmapped:<source>/<medium>``; include_in_channel_reporting=false rows are
honest origins but not marketing touches.
"""
from __future__ import annotations

from typing import NamedTuple, Optional, Sequence


class Resolution(NamedTuple):
    channel: Optional[str]
    platform: Optional[str]
    reportable: bool


def _norm(v: Optional[str]) -> Optional[str]:
    v = (v or "").strip().lower()
    return v or None


class Resolver:
    def __init__(self, rows: Sequence) -> None:
        # Precompute normalized match keys once; row order irrelevant.
        self._rows = [
            (
                _norm(r.observed_source), _norm(r.observed_medium),
                _norm(r.observed_content),
                # specificity = how many concrete (non-wildcard) fields
                sum(x is not None for x in (
                    _norm(r.observed_source), _norm(r.observed_medium),
                    _norm(r.observed_content),
                )),
                r,
            )
            for r in rows
        ]

    def resolve(
        self,
        source: Optional[str],
        medium: Optional[str],
        content: Optional[str],
    ) -> Resolution:
        s, m, c = _norm(source), _norm(medium), _norm(content)
        if s is None and m is None and c is None:
            return Resolution(None, None, False)
        best = None  # (neg_specificity, id) minimized
        for rs, rm, rc, spec, row in self._rows:
            if rs is not None and rs != s:
                continue
            if rm is not None and rm != m:
                continue
            if rc is not None and rc != c:
                continue
            key = (-spec, row.id)
            if best is None or key < best[0]:
                best = (key, row)
        if best is None:
            return Resolution(f"unmapped:{s or ''}/{m or ''}", None, True)
        row = best[1]
        return Resolution(
            row.canonical_channel, row.platform,
            bool(row.include_in_channel_reporting),
        )


def build_resolver(rows: Sequence) -> Resolver:
    return Resolver(rows)
```
