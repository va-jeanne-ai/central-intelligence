Central Intelligence

Continuously syncs a client's business data and marketing platforms into one database, computes metrics, generates evidence-backed recommendations and AI insights, and serves it all through dashboards and department AI directors you can chat with.

General Flow

Phase 1 · Ingest
⚡
Scheduler fires on a staggered clock
Celery beat in backend/app/tasks/celery_app.py — hourly, 6-hourly, and nightly jobs
⚙
Sync the client's source database
Hourly read-only pull from the client's mirror DB, incremental via watermark
⚙
Pull connected platforms
Mailchimp, Meta social + ads, social comments, Gmail, Drive, Calendar
⚙
Manual sync always available
Per-integration Sync-now buttons and a data-freshness monitor
Phase 2 · Embed
⚙
Every new record joins the embed queue
RAG-everything: source-DB rows, files, emails, comments enqueue embed_pending
⚙
Queue drains every 2 minutes
Chunk → Voyage embeddings → pgvector, under a token budget (tasks/embed_worker.py)
Phase 3 · Compute
⚙
Metric catalog runs daily snapshots
Declarative SQL registry per department, incl. per-rep splits (analytics/registry.py)
⚙
Trends and signals recomputed
Period-over-period verdicts, funnel stats, rolling market signals
Phase 4 · Recommend
⚙
Every metric checked against thresholds
Statistical, no heuristics — runs right after snapshots (analytics/recommend.py)

Key Features

Statistical recommendation engine
Recommendations fire only when real data crosses a threshold, and every one cites its numbers.
Department AI directors
CI orchestrates three department-scoped directors that delegate to specialists — reasoning over real data, never inventing figures.
RAG-everything knowledge base
Every synced source is embedded into a pgvector store within minutes, so chat answers are grounded in the full corpus.
Live integrations catalog
A backend registry drives credential forms, on-demand syncs, and a freshness monitor for every connected platform.
Cost-safe by design
Mock mode and seed-data fallbacks keep the whole pipeline runnable with zero paid API calls.
